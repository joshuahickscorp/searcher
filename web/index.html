        Privacy

        Searcher treats a search as a private request, not as content to publish or train on.

        • Uploads are private by default. They are sent only to the configured search service.
        • Images, text, and tags are not used for training by default.
        • This site has no hidden analytics, no accounts, and no third-party scripts.
        • Nothing here is uploaded to a third-party model unless the search service is explicitly configured that way.
        • A search can be deleted. Deletion is requested from the results panel when a search is open.
        • Retention is a property of the search service, not of this page. This page stores only local drafts, display preferences, and recent search identifiers in this browser.
        • Diagnostics should be inspectable before anything is exported. This page never embeds a secret, token, or credential.

        The static files of this interface contain no keys. The API address is deployment configuration, overridable with a ?api= query parameter for local testing.

        Limitations

        Searcher is not a professional authenticator. It ranks evidence under a declared policy and shows calibrated uncertainty. A result in Real is still an estimate.

        Real means high confidence this is the same item as the one you photographed — an identity judgement, not an authenticity one, and never a professional authentication guarantee. Possibly Real means the item may match, but important evidence is missing or conflicting.

        Retrieval is measured in artifacts/searcher-public-benchmark.receipt.json: recall@1 0.771, recall@5 1.0, MRR 0.867 over 35 queries. Those are identity figures. The receipt also reports false Real 0, and that number is not evidence about authenticity: it is measured with photograph screening absent, so it does not cover a listing that reuses the brand’s own images. Real is currently unavailable for any candidate whose photographs were never screened.

        A replica listing can never be ranked Real. Replica sources are not searched; the reason is below.

        Searcher does not claim:

        • guaranteed authenticity;
        • professional authentication;
        • counterfeit detection with universal accuracy;
        • exhaustive coverage of the internet;
        • access to every marketplace;
        • guaranteed purchase availability;
        • guaranteed seller trustworthiness;
        • guaranteed lowest price;
        • universal brand, category, or era coverage;
        • superiority over conventional image search without a frozen comparison;
        • that a blocked source contained no result;
        • that a result is authentic solely because a marketplace says it is authenticated;
        • that a result is fake solely because the model is uncertain.

        Searcher does not place orders, enter payment information, negotiate with sellers, or publish accusations against sellers. Listing pages open in a new tab. Checkout is never embedded.

        Why replica sources are not searched

        Searcher can rank a listing as Replica, and a listing from a replica source can never be ranked Real. It does not, however, search replica marketplaces, and that is a limit of what may be fetched rather than a limit of the software.

        The three replica sources this project reviewed are all refused for stated reasons: Taobao’s robots file disallows the query-string URLs its item pages use; Weidian serves no robots file, redirecting /robots.txt elsewhere; and Yupoo returns a 404 page for both /robots.txt and its album paths. Searching any of them would mean ignoring a robots rule or working around an anti-automation gate. Searcher does neither, so the result is no replica coverage at all — not partial coverage, and not silence.

        This means an absence of replica results is never evidence that no replica exists. It only means Searcher was not permitted to look.

        A missing candidate is simply absent. If some candidates did not meet policy, that is all the interface will say.
