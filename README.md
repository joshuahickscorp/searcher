# Searcher

Evidence-ranked multimodal search engine for hard-to-find physical products.

Give it images, partial text, and tags. It forms competing identity hypotheses,
compiles multilingual queries, searches admitted public sources, compares
candidates at part level, evaluates authenticity evidence separately from item
match, verifies listings are live, and returns two lists — **Real** and
**Possibly Real** — with the evidence behind each placement.

Standing authority: [docs/SEARCHER_FULL_IMPLEMENTATION_BIBLE.md](docs/SEARCHER_FULL_IMPLEMENTATION_BIBLE.md).

Status: pre-alpha, under construction. No claims are made until the benchmark
in the Bible supports them.
