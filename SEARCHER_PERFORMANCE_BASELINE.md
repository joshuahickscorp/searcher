# Searcher performance baseline

Bible §39 name. Draws from `docs/architecture/PERFORMANCE.md`.
Numbers below are from committed receipts, not from this session's
clock.

A live campaign plans queries, fetches admitted sources under robots
and rate policy, normalizes, clusters, matches, and checks liveness.
A precomputed image index answers a lookup against work that already
happened. Those are different operations. A cold live campaign cannot
equal an index lookup.

## Engineering targets

Recorded in `artifacts/searcher-performance.receipt.json` as
`targets_ms`. Command: `bash scripts/bench_latency.sh`.

```text
UI first byte                 < 200 ms
search creation response      < 300 ms
first progress event          < 500 ms
first candidate on screen     < 3 s   (warm)
repeat/overlapping search     < 1 s   to first result
health                        < 50 ms
capabilities                  < 100 ms
```

## Live campaign wall time

`artifacts/searcher-speed.receipt.json`, host `Mac-Studio`,
measured 2026-08-17T02:30:32Z, three runs each.

| | median_wall_ms | run walls (ms) |
|---|---:|---|
| before | 199474.107 | 199474.107, 203276.165, 197236.244 |
| after | 95704.578 | 99032.254, 95704.578, 86524.518 |

Reduction ratio 0.5202. Dominant before cost: verifying live links
(~150 s) plus a serial source walk. After, independent sources start
together. Remaining floor: live-check of several same-host KIND
listings under rpm=12 / crawl-delay.

Command that produced the speed receipt is recorded in that file's
`before` / `after` bodies (live campaign harness on this host). It
is not regenerated by `benchmark --all`.

## Model calls

The search path records `model_calls: 0` on the fixture campaigns in
the performance receipt. Live runners construct budgets with
`model_call_limit=0`
(`src/searcher/workers/api_campaign.py`,
`src/searcher/sources/live_runner.py`). The only learned component
is a local DINOv2 ViT-S/14 loaded from a traced file. A search never
downloads weights.

## What is not established

- Time to first Real result. Nothing this project publishes reaches
  Real, so the metric has no live sample.
- A dollar cost. There is no monetary ledger. Cost is pages, bytes,
  images, fetches, model calls (zero), and wall time.
- A regenerated live-campaign wall-time receipt at SHA `31e6004`.
  The 199474 → 95705 figures are the committed speed receipt, not a
  re-run in this session.
